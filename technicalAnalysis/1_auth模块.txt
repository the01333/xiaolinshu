<授权服务>

1. 接口
[登录]:
    这里使用 SaToken 作为鉴权框架, 用户登录注册有两种方式, 一种是手机号短信验证码登录, 一种是手机号密码登录; 
走 rpc 去调用用户模块, 例如根据手机号查找用户、注册用户（1️⃣存在直接返回, 2️⃣不存在直接注册）, 
之后把用户 ID 存入 SaToken 并直接返回 token
    1️⃣如果用户不存在直接注册, 调用分布式 ID 服务去获取小林书 ID 和用户 ID, 用户表和用户角色表数据入库后,
还需要把用户角色存入 redis
    2️⃣如果存在直接登录

[注销]:
    直接调用 SaToken 的 logout()
    
[修改密码]:
    走 rpc 调用用户服务
   
[发送短信验证码]:
    使用 aliyun 的 短信 sdk, 封装 API 工具

2. 其他配置
    把 aliyun 的 accessKey 和 secretKey 抽到 nacos 的配置中心里支持热更新
